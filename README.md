# Автоматизированная система проветривания с контролем CO₂ и температуры

Проект создан в рамках школьной проектной конференции летом 2025го.  
Цель — поддержание комфортного микроклимата в жилой комнате за счёт автоматического проветривания по датчикам температуры и углекислого газа (CO₂).

Система состоит из двух блоков, связанных по радиоканалу (nRF24L01):
- **Настольный блок управления** с датчиками и экраном
- **Исполнительный блок на окне** с сервоприводом

Оба блока изготовлены на самодельных печатных платах.

## Принцип работы

1. Настольный блок измеряет температуру и уровень CO₂.
2. Пользователь задаёт комфортную температуру, допустимый уровень CO₂ и длительность открытия окна.
3. Микроконтроллер настольного блока анализирует показания и принимает решение о необходимости проветривания.
4. По радиоканалу nRF24L01 отправляется команда на оконный блок.
5. Сервопривод открывает/закрывает окно.
6. После проветривания уровень CO₂ снижается, температура корректируется — система возвращается в режим мониторинга.

Цикл повторяется, поддерживая комфортные параметры воздуха без участия человека.

## Реализованные возможности

### Настольный блок (управление + датчики)
- Микроконтроллер Arduino Nano
- Инфракрасный датчик CO₂ (MH‑Z19B)
- Датчик температуры (DS18B20)
- ЖК‑экран (1602) с интерфейсом на энкодере
- Радиомодуль nRF24L01 для связи с оконным блоком
- Меню настроек:
  - Комфортная температура
  - Приоритетность температуры над CO2
  - Время открытия окна
  - Текущие показания датчиков
  - Статус окна (открыто/закрыто)
- Самодельная печатная плата (односторонняя)

### Оконный блок (исполнительный)
- Arduino Nano
- Сервопривод DS3240 с тягой к оконной ручке
- Радиомодуль nRF24L01
- Самодельная печатная плата

## Особенности реализации
- **Защита от ложных срабатываний:** гистерезис по температуре и CO₂, минимальный интервал между проветриваниями.
- **Пользовательский интерфейс:** поворотный энкодер с кнопкой, многостраничное меню на ЖК‑экране.
- **Полный цикл изготовления:** от принципиальной схемы и трассировки плат до корпуса, который мы сами смоделировали и распечатали.

## Что можно улучшить
- Добавить датчик влажности (DHT22) для более полного контроля климата.
- Заменить радиоканал на Wi‑Fi (ESP32) для удалённого мониторинга через смартфон.
- Реализовать адаптивный алгоритм проветривания с учётом прогноза погоды.
- Сделать управление не одной, а несколькими фрамугами.
